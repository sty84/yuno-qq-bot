评分审核
对单条记忆决策 / 单轮对话质量做五维评分。评完立即刷新评分驱动的行为参数。

            

              

                
                
              

              
            

          

          

            📏 评分标准（点开看详细规则）
            
评分对象：单条记忆处理决策（create=存了什么 / reject=该不该存 / merge=合并 / update=更新）。五维 1~5：5=很好　4=好　3=一般　2=差　1=很离谱，拿不准就打 3。

            

              

                
维度评什么打 5 分（很好）打 1 分（很离谱）

                
                  
提取 extraction提取的事实准不准、细节全不全名字/数字/品种/时间等细节都保留了，没瞎编提取内容与原话不符，或编造了原话没有的细节

                  
决策 decision这条该不该存、处理方式对不对重要事实存了；玩笑/临时情绪/寒暄正确地没存重要事实漏存，或垃圾/玩笑话入库了

                  
置信度 confidenceconf 数字标得跟实际可信度匹不匹配用户亲口说的给高可信度；AI 猜的给低证据不足却给高可信度（或反之）

                  
来源 provenance来源标得对不对（是谁说的）用户说的标"用户"；AI 想法没混入用户记忆来源张冠李戴，AI 自述被当用户亲口说

                  
隐私 privacy敏感信息（手机/证件/财务/健康）处理得对不对敏感信息加密或标私有，不会被其他人召回敏感信息明文入库、还能被群聊召回

                
              

            

            
对话质量评分五维：remember 记忆呼应 / natural 自然度 / emotional 情绪恰当 / proactive 主动合宜 / boundary 边界感。

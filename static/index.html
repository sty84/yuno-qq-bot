消融实验 · 热插拔开关

    
开关实时修改 config 并落盘：立即影响本管理台的评测；bot 进程通过后台循环的 reload_if_changed 自动生效（无需重启）。"运行消融"用同一套 probes 逐个关掉机制，看每个机制的贡献。

    

    
    

    

    

  


  

    

    
按模块 token 消耗

    

    
模块 = LLM 调用用途（chat 对话 / extract 提取 / rerank 检索重排 / cognitive 认知循环 / scenario 回放评分 / proactive 主动消息 / …）。七路检索本身是本地计算、零 token，只有 llm 重排和云端向量会花钱。

    
检索路径 token（llm 重排归因）

    

    
每次 llm 重排按"本次参与了哪几条检索路径"归因，能看到重排成本主要落在哪条路上。

    
按天累计

    

    
机制权衡：token 成本 × 消融效果

    

    
对照看：某机制在成本表里占比高、且消融矩阵里关掉它 delta≈0（不损失效果），就是该砍的；占比低但关掉明显退化（如 rerank），说明它是值钱的。

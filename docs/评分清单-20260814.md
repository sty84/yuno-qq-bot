## 污染扫描（2026-08-16 新增 · 防自我强化循环）

**背景**：LLM 提取幻觉会把用户消息里不存在的内容固化成 `source=user` 记忆（"颜色是橘色"案例）；
这类假事实随后会"合法化"后续编造的来源声明（"你自己说的"），形成自我强化污染循环。
ingest 侧的 `_fact_grounded` 挡住新提取，本工具清理**存量**。

**命令**：`./venv/bin/python tools.py pollution-scan [--scope xxx] [--apply]`

**判定**：对每条 `source=user` 记忆，提取内容词（≥2 字、去噪音词），在用户历史消息
（conv_log.user_text + sessions.summary）里查字面出处，按覆盖率分级：
- `strong`：陈述句出处 ≥2/3 → 用户亲口说过 → 保留
- `partial`：部分出处 → 提取概括/推断 → 降级为 `ai_edit`（不再充当"用户亲口说"证据）
- `weak`：仅问句命中 → 语义反转（用户问"你玩过怪物猎人吗"被提取成"用户玩过"）→ 删除
- `none`：无出处 → 提取幻觉固化 → 删除
- `empty`：无内容词（全噪音）→ 无法判定，报告留待人工

**2026-08-16 首次执行结果**：24 条 user 记忆 → 保留 10、降级 4（伞/适合干这一行/白巧克力×2）、
删除 9（密码 123456、玩过Phigros/Arcaea/Muse Dash/音游、怪物猎人、战地、弹奏卡副歌、阿拉蕾是雪貂）、
人工清理 1（"旧说法"）。audit 表留痕 `pollution_del` / `pollution_demote`。
